# CTO — Website Project

## About the Project

CTO is a web development project built using HTML, CSS, and JavaScript. The repository contains multiple web pages for login, registration, and post-related functionality.

## Technologies Used

- **HTML** — Web page structure
- **CSS** — Styling and layout
- **JavaScript** — Client-side scripting

## Project Structure

```text
CTO/
├── index.html
├── login.html
├── register.html
├── posts.html
├── new-post.html
├── main.js
├── main.min.js
├── style.css
└── README.md
```

## Pages

- `index.html` — Main page
- `login.html` — Login page
- `register.html` — Registration page
- `posts.html` — Posts page
- `new-post.html` — New post page

## Getting Started

1. Download or clone this repository.
2. Open the project folder on your computer.
3. Open `index.html` in a web browser to view the website.

## Purpose

This project demonstrates the organisation of a multi-page website using core front-end web technologies.
